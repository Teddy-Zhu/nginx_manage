# 内置组件

首次部署只安装面板。需要某项功能时，在「软件商店」选择组件并安装。各组件使用独立 Docker 容器，配置和数据保存在宿主机。

| 组件 | 首次安装 | 版本切换 |
| --- | --- | --- |
| Nginx | 点击「安装 Nginx」，使用安装包预置的镜像，支持离线安装 | 从项目发布的稳定版或 Beta 镜像中选择。拉取前核对签名与镜像摘要 |
| Fail2ban | 选择版本和开机启动选项。面板直接拉取上游 Docker 镜像 | 从面板内置版本目录选择，镜像按摘要固定 |
| FRP 服务端 | 填写连接与端口设置，再选择版本。面板直接拉取上游 Docker 镜像 | 从面板内置版本目录选择，镜像按摘要固定 |

Fail2ban 可以保护 SSH、面板登录及网站认证。手动配置规则和信任名单后，可在「登录防护」查看和解除封禁。FRP 在「FRP 服务端」管理客户端连接、端口映射和网站转发。软件商店负责安装、运行管理和日志，具体业务配置在各自功能页面操作。

版本列表分别显示组件版本和上游软件版本。选择较旧版本时会提示配置或数据兼容风险，可以继续降级。安装、启停和版本切换的进度及失败原因可在「操作记录」查看。

Nginx 镜像由项目独立发布。Fail2ban 和 FRP 的版本及上游镜像摘要随面板内置版本目录发布。核心更新后，组件在用户发起版本切换时更新。发布流程见[发布指南](publishing.md#内置组件版本目录)。
