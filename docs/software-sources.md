# 软件源

软件商店分为内置软件和第三方软件。默认只安装面板及必要的 Nginx；Fail2ban 和第三方软件均由用户点击安装。

## 内置 Fail2ban

Fail2ban 使用现成的 `crazymax/fail2ban:debian` 镜像部署，安装时不访问本项目的 GitHub Release，也不在宿主机安装 Python 或编译 Fail2ban。来源为 [crazy-max/docker-fail2ban](https://github.com/crazy-max/docker-fail2ban)。默认开启开机启动；安装、启停、更新和卸载都有任务状态与日志。

在“登录防护”添加 SSH、面板登录或网站认证规则，设置失败次数、统计时长、封禁时长及保护端口；信任名单支持 IP 和网段。封禁名单可查看并解除封禁，也可手动封禁地址。SSH 日志自动选择系统日志或认证日志；面板和网站使用本系统管理的日志。网站认证规则针对 HTTP 401，不能自动识别任意网站自定义的登录失败页面。

容器使用宿主网络及必要的 `NET_ADMIN`、`NET_RAW` 权限，读取日志并通过独立的 `NGINXPANEL_F2B` 规则链与 IPSet 地址集合限制受保护端口，不清空原有防火墙规则。每条规则最多保护 15 个 TCP 端口；IPv4 和 IPv6 分别管理。使用镜像内的工具，不依赖宿主安装 Fail2ban 或 Python，也避免容器 nftables 与宿主旧版工具之间的集合格式冲突。保护范围是宿主入站端口，包括默认以宿主网络运行的 Nginx；不扩展到其他桥接容器的转发端口。已有其他防火墙限制仍然生效，信任名单不会绕过它们。安装来源可改为兼容镜像地址。

安装时自动准备所需的宿主防火墙内核模块，并配置开机加载；容器无需加载内核模块的权限。手动封禁和解封会检查实际规则结果。更新保留规则和数据，启动失败时尝试恢复原容器；卸载移除本软件的开机加载配置，保留防护配置和数据库，重新安装后继续使用。默认只安装面板和必要的 Nginx，Fail2ban 仍需用户自行点击安装。

## 导入第三方软件源

在“软件商店 → 第三方软件”选择“添加软件源”，输入远程 JSON 地址，或选择本地 JSON 文件。支持 GitHub 文件页面链接、Raw 链接及其他 HTTP/HTTPS 配置地址；读取配置使用宿主 Agent 配置的 HTTP/HTTPS 代理环境。镜像支持本地和局域网来源，下载遵循 Docker 自身的镜像源及代理配置。配置不得超过 24 KB。

导入只添加软件列表。查看软件描述和端口后，点击对应的“安装”。同一软件源可点击“更新列表”重新读取原地址；远程配置修改不会自动重启已安装的软件。需要安装新配置时再点击“更新软件”。已有软件源标识不可通过重复导入覆盖。

第三方软件以 Docker 容器运行，机器需具备可用的 Docker。软件更新先拉取镜像，再重新创建该软件的容器；名称相同的数据卷继续使用。启动失败会尝试恢复原容器，失败详情保留在操作日志中。卸载移除容器并保留数据卷；卸载此源的软件后可删除软件源。

配置示例见 [source.json](../examples/software/source.json)：

- `schema`：当前为 `1`。
- `id`、`name`：软件源标识和显示名称；标识由小写字母、数字和连字符组成，最长 40 字符，首字符为字母。
- `applications`：软件列表，每项包含 `id`、`name`、`description`、`image`。
- `ports`：可选，主机端口 `host`、容器端口 `container`、`protocol`（`tcp` 或 `udp`）。安装前应确认端口未被占用。
- `volumes`：可选，数据卷名称 `name` 和容器内目录 `target`。只管理软件自己的命名数据卷。
- `environment`：可选，环境变量名称与值。
- `url`：本地文件导入时可选，用于后续更新列表。通过远程地址导入时，系统记录实际导入地址。

仅导入可信来源。配置不支持执行宿主机脚本、特权容器或任意宿主目录挂载，也不修改其他容器。文件中不应发布真实密码。

## 系统更新

进入“设置 → 系统更新”，依次检查更新、下载更新、立即更新。无需进入维护模式。下载时面板保持运行；宿主 Agent 独立完成替换，短暂重启后面板启动并自动执行数据库迁移。Docker 部署拉取发行对应镜像并重新创建面板容器；原生部署切换已准备的程序并重启面板服务。

更新保留数据，失败时查看对应任务日志或宿主服务日志。需要更高管理服务协议的发行通过安装脚本更新。系统更新仍使用安装时配置的发行源及签名校验；第三方软件源不能替换面板程序或内置软件。

卸载本系统或关闭登录防护模块前，请先在软件商店卸载相应软件，避免留下无人管理的防护或容器。软件卸载保留配置和命名数据卷。
