# P0 工程合同

配置修订通过一个服务写入：原文、SHA-256、资源绑定与结构化投影同事务保存；原文及投影使用节点主密钥 AES-256-GCM 加密，附加数据绑定修订与逻辑资源 ID。完整原文接口要求 `config.secrets`，写入同时要求 `config.write`；浏览器读取/编辑原文须在五分钟内重新认证。安全指令还要求 `security.write`。

Crossplane 0.4.89 负责配置树语法分析，独立源码区间负责定点修改。稳定资源通过块前的 `# nginxpanel:resource <UUID>` 关联，不按域名猜测；include 文件继承实际调用位置的上下文，多处接入的资源文件拒绝歧义映射。当前表单映射为 HTTP 域名、单条监听、默认 location 的单上游与超时、请求体大小，以及 Stream 单监听、单上游与超时。重复指令、变量、共享 include、参数中含注释及非唯一默认 location 拒绝相关表单修改；其他原文保留。未登记指令可保存在独立草稿，但不能成为有效期望状态。未标记块保留原生可编辑状态，不自动认领。

配置树 `base_version` 指向当前有效期望状态；草稿使用独立不可变修订，不改变该版本。错误草稿没有有效投影、不会创建任务。保存不等于实际应用。当前任务仅执行独立 Agent 策略复核，阶段为 `policy_checked`；它不调用 `nginx -t`、reload 或宣称流量已经切换。实际 Nginx 发布、运行探针与回滚在 P1 接入。

Agent 只监听 Unix Socket，使用 `SO_PEERCRED` 校验唯一授权 UID。生产 Agent 要求 root；开发 Agent 不执行宿主机写操作。Agent 不访问业务数据库。策略默认不允许外部 include、任意路径、动态模块、Lua/JS/Perl、任意文件服务与可执行扩展。未来开放系统只读 include 或模块必须通过 root 策略清单，不能由 API 放宽。

Agent 操作记录使用独立文件、原子 rename、文件与目录 fsync。记录只含操作 ID、输入摘要、修订、阶段与期限，不含原文、秘密或日志载荷；最多 2048 条，达到上限须本机维护，不能无界写入。未来 DNS/防火墙流程必须在副作用前持久化旧状态与期限，确认或补偿由 Agent 独立完成，重启先恢复未确认操作，恢复记录不进入业务备份。尚未接入这些适配器时不得开放写入。

组件信任合同：来源、固定版本、架构、ABI、文件散列和许可证进入签名清单；root 独占激活目录。安装、启用、启动与卸载是不同动作；系统组件不自动迁移或替换。实际组件安装/升级及健康检查在 P4 接入，当前不接受任意组件包或系统软件安装请求。

资源预算见 `internal/limits`。配置树最多 128 文件、单文件 256 KiB、总计 2 MiB、嵌套 32 层；HTTP/IPC 请求最多 4 MiB；任务排队最多 100，当前单 worker；列表每页最多 100。监控、日志、暂存、备份与 SSE 的初始预算已固定，启用对应功能时必须在实际入口执行，常量本身不代表该功能已经交付。

DNS 能力诊断只给出候选所有者，尚未验证的所有组合只读。工具已安装、模块启用、服务运行、系统兼容性验收是独立事实；未知运行状态返回 null。未接入 Agent 时，Web 不展示容器/本进程环境为宿主机事实。
