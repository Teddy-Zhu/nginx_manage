当前边界：原生树与常用字段共同保存修订。HTTP/Stream 支持创建、复制、停用、删除、多监听、私有加权上游、超时与日志字段；HTTP 补齐路径示例、WebSocket/SSE 预设、头、缓冲/缓存、上游 TLS、可信代理、访问列表和 WAF 绑定。访问列表与 WAF 页面通过文件路由扫描自动接入，支持复用黑白名单，以及限速/并发/请求体/方法/路径策略；缺失模块给出原因，观察与豁免边界明确，原生重叠规则不猜测覆盖；保存后仍须应用。WAF 字段保留在同一原文修订中，受管日志已接入策略及限流状态字段，事件查询通过日志页的防护条件接入。P1 已接入真实 `nginx -t`、不可变候选与原子指针、专用实例 HUP、修订探针/监听归属/TLS 指纹确认、失败补偿及 Agent 重启恢复；任务与前端已接通，只有运行确认后才更新已生效修订。已接受但记录缺失的操作停止重复执行；不确定的 IPC 提交继续使用原标识核对。

生产执行须由 root 在本机指定可信 Nginx 二进制及独立 worker 账户，先通过 `nginx-init` 创建无站点基线，再由专用服务使用固定 prefix/config 启动。开发 Agent 保持只读。P4 原生首次安装已接入 root 批准产物、账户/目录权限分区及 systemd 注册，见 deploy/native/README.md；签名更新、可信组件和完整 Docker 注册继续实施。未在当前宿主机执行任何初始化、服务启动或配置应用。

手动证书可导入、增加不可变版本、查看 SAN/签发者/有效期及引用、删除未引用资源；链和私钥加密存储，站点成对选择并校验覆盖。证书目录由 Agent 在发布任务中原子准备，版本及依赖散列与配置候选一同核对，沿用原有 TLS 指纹确认和失败补偿。HTTP/HTTPS 混合站点支持 308 跳转和 HSTS 字段，无法可靠映射或缺少模块时说明原因。证书页面沿用文件路由自动扫描。历史修订仍引用的证书保留，历史清理入口尚未交付。

原文差异可比较编辑内容与历史修订，按文件展示变更和保守影响范围；发布副本提供只读外部检查及单文件草稿捕获，逐字可还原时剥离生成控制。快照变化或期望树同文件冲突时拒绝自动合并，符号链接/硬链接/越界及超限内容不读取。捕获不写宿主机运行配置。显式恢复提供已保存期望修订预览、快照复核与互斥任务，使用新发布目录保留原外部副本；切换后不回滚到外部内容，结果不确定则保留恢复记录并阻止冲突操作。Agent 重启按独立记录继续确认候选；任务同时核对逻辑修订与物理发布身份，确认后才更新已生效修订。清单损坏或目录检查不完整须本机处理；损坏证书需新版本绑定或本机修复。

ACME 已接入固定 lego/v5、独立测试/正式账户及加密 DNS 凭据；Cloudflare、阿里云 DNS、腾讯云 DNSPod 的 DNS-01 签发、传播检查、订单恢复和不可变证书版本已贯通 API 与文件路由页面。账户注册、证书签发、生命周期调度和 Nginx 分别使用独立 worker。私钥、CSR、凭据快照和订单提交意图先持久化；重启先查询原订单，创建结果不确定且没有订单地址时停止重复申请，人工新建须明确确认。DNS 操作持久保存 CNAME 目标、区域、原有同值记录和创建 ID；清理按本次值及记录 ID 核对，保留原有 TXT。DNS 创建响应不确定且查询未发现记录时保留恢复记录与锁，不将暂时不存在视为已清理，持续无法确认须本机处理。证书保存与订单结果同事务，清理失败仍保留证书并允许恢复。测试证书显式标记且不更改系统信任库；签发默认不切换站点绑定或应用运行配置，可单独显式开启自动部署。实现已接入并审阅，尚未向 CA/DNS 发起实际请求，远端行为待集中验证。

自动续期和自动部署策略默认关闭，首次申请仍显式发起。每个证书版本保存一次实际有效期 1/2–2/3 区间的随机续期时刻，签发后尽快检查 ARI；有效 CA 窗口内均匀选择时刻，窗口不变时保留原选择。ARI 检查期限和响应头即时持久化，成功轮询间隔限制在 1 分钟至 24 小时，临时错误指数退避，长期错误按约 6 小时重新检查；过期或已被新版本替代的证书停止 ARI 查询。依据 RFC 9773（https://www.rfc-editor.org/rfc/rfc9773.html）。续期携带原证书标识，复用已知未终止订单；只有明确终止或已有签发结果才自动创建下一订单。连续六次准备/签发失败后暂停，结果不确定立即停止并要求人工恢复；旧证书和错误保留，人工重置不绕过 CA 冷却期限。

证书部署页面通过文件路由自动接入，可预览并切换全部现有 TLS 证书链/私钥引用；信任链用途须人工明确处理。有待应用配置时等待，不连带发布其他改动。部署修订、标准 Nginx 应用任务和关联记录同事务保存；自动策略在提交前再次核对，每个证书版本最多自动提交一次应用任务。失败/补偿/恢复沿用原执行器，实际绑定状态从最近确认的已应用修订读取，包含停用站点的配置引用，独立于签发和任务排队状态。首次绑定仍在 Nginx 配置页完成；任务失败后可在该页检查候选修订并明确重试或恢复。实现及源码审阅完成，等待集中验证。

HTTP-01 复用受管 Nginx 的 80 端口，站点须显式启用验证入口并保存、应用；申请端确认公网入口和 A/AAAA 指向，系统解析及本机材料响应另行预检，最终可达性由 CA 确认。原文保留无宿主机路径的占位 location，执行器在不可变副本生成独立 Unix socket 代理及仅针对验证路径的重写/ACL/认证/限流豁免；业务路径不改变。Agent 按订单持久保存有界租约和材料，逐次检查域名、token、方法与到期时间，进程停止后不留静态可访问材料。订单意图及递增租约序号先于 IPC，持久清理记录阻止迟到请求复活材料，重启先清理原租约再恢复已知 CA 订单；清理未确认保留恢复状态及已取得证书。验证与 Nginx 操作双端互斥；新建订单或停用不能抛弃未确认清理的材料。页面、API、自动续期与任务阶段已接入，未启动服务或联系 CA，等待集中验证。
