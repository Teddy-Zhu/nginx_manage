# 虚拟机功能实测（2026-10-28）

本轮结合 Chrome 页面操作、正常管理接口和真实网络连接，验证 Nginx、Fail2ban、防火墙及网站防护的实际效果。发现的三处缺陷已修复、部署，并复验受影响场景。本轮已测范围通过，不代表所有模块和所有部署环境均已验收。

## 发现并修复的问题

1. **Nginx 状态采样可能阻塞配置应用。** 原实现反复创建 Docker exec 执行编译信息查询，调用取消后可能遗留未启动的执行记录，导致后续配置检查被拒绝。改为核验实际运行进程及不可变镜像绑定，读取已校验的编译信息。修复后从页面应用成功，真实反代与转发通过。
2. **防火墙误拒绝与 Fail2ban 共存。** Fail2ban 的独立 legacy 规则触发了防火墙对混合后端的一律拒绝。改为在全部规则视图可读、没有其他受管防火墙冲突时，允许操作本工具登记的独立 nftables 表；其他来源的限制继续生效。共同拦截和外部规则保留均已实测。
3. **Fail2ban 修改防护端口后仍保留旧端口规则。** 普通 reload 未重启已启动的 IPSet 动作。配置提交与失败恢复改为同时重启动作，实测增加和移除端口都立即生效。测试机中修复前已产生的那条测试端口残留已精确清理，未清空外部规则。

相关集中检查：`go test ./internal/agent ./internal/firewall ./internal/fail2bancontainer ./internal/nginxcontainer` 完成，有用例的包通过，`fail2bancontainer` 没有既有单元用例；程序构建通过。补充的回归用例仅覆盖本轮混合规则误拒绝及观测不完整时的拒绝条件。Fail2ban 的实际行为通过上述容器与网络验证。
